# Учебная практика 2024. Реализация REST-API сервиса для бранирования билетов в кинотеатр

Бизнес-сценарии:

**Сценарий 1.** Система бронирования и покупка билетов

Проверка уникальности продажи билета и его временная блокировка для других пользователей на 15 минут. Если билет не оплачен в этот период, он снова доступен для покупки.

**Сценарий 2.** Алгоритм системы рекомендаций

Рекомендация пользователям фильмов на основе их покупок и предпочтений по жанрам, предлагаются фильмы таких жанров, которые пользователь предпочитает и которые он еще не смотрел.

**Сценарий 3.** Динамическое изменнеие цены

Система автоматически корректирует стоимость оставшихся билетов в зависимости от их остатка. Если количество оставшихся билетов составляет менее половины от общего числа мест в зале, цена на оставшиеся билеты для этого сеанса повышается.
